Git and GitHub Basics

  1. Git Commands and Their Uses

    • Initialize a repository: git init
    • Stage all files: git add .
    • Commit with a message: git commit -m "Initial commit"
    • Push to a remote repository: git push origin main
    • Pull the latest changes: git pull origin main

  2. Difference Between git fetch and git pull

    git fetch: Downloads new commits and references from the remote repository without merging them into the current branch.

    git pull: Downloads remote changes and integrates them into the current branch, usually by merging or rebasing.

  3. Create a GitHub Repository and Push a Text File

    Step 1: Sign in to GitHub and create a new repository named web-design-practice.

    Step 2: Create a text file named hello.txt on your computer.

    Step 3: Open Command Prompt or the terminal in your project folder.

    Commands

    git init
git add hello.txt
git commit -m "Add hello text file"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/web-design-practice.git
git push -u origin main

    Replace YOUR-USERNAME with your actual GitHub username. If the repository already has a remote named origin, update it with git remote set-url origin YOUR-REPOSITORY-URL.

    Repository link: https://github.com/YOUR-USERNAME/web-design-practice

    Replace the placeholder with your real username and share the link after pushing the file successfully.

  4. Difference Between a Fork and a Pull Request

    Fork: Creates your own copy of another user's repository under your GitHub account.

    Pull Request: Proposes changes from one branch or repository to another so they can be reviewed and merged.

  5. Create a Branch, Commit, and Merge into Main

    Step 1: Switch to the main branch and update it.

    git switch main
git pull origin main

    Step 2: Create and switch to feature-test.

    git switch -c feature-test

    Step 3: Create a file named feature.txt and add some text to it.

    Step 4: Stage and commit the file.

    git add feature.txt
git commit -m "Add feature test file"

    Step 5: Switch back to main and merge the branch. 

    git switch main
git merge feature-test

    Step 6: Push the updated main branch to GitHub.

    git push origin main
