SDLC, Agile, Scrum and Jira

  1. Six Phases of SDLC in Order

    • Planning: Defines the project goals, scope, budget, resources, and timeline.
    • Requirements Analysis: Collects and documents what users and stakeholders need from the software.
    • Design: Creates the software architecture, database structure, and user interface design.
    • Development: Developers write the code to build the software application.
    • Testing: Checks the software for defects and verifies that it meets the requirements.
    • Deployment and Maintenance: Releases the software to users, fixes issues, and provides updates.

  2. Three Differences Between Agile and Waterfall

    • Approach: Agile develops software in small, iterative cycles, while Waterfall follows sequential phases.
    • Requirements: Agile can accommodate changing requirements, while Waterfall generally defines requirements early and manages changes more formally.
    • Testing and Delivery: Agile encourages frequent testing and incremental releases, while Waterfall typically follows a planned sequence with testing after development.

  3. Three Main Scrum Roles

    • Product Owner: Maximizes product value and manages the Product Backlog.
    • Scrum Master: Helps the team understand Scrum, removes or helps resolve impediments, and supports effective Scrum practices.
    • Developers: Create a usable product Increment during each Sprint and maintain its quality.

  4. What Is a Sprint in Scrum?

    A Sprint is a fixed-length period during which the Scrum Team works toward a Sprint Goal and creates a usable product Increment.

    Typical Duration: One to four weeks. A Sprint is one month or less.

  5. Meanings of Jira Board Columns

    • To Do: Tasks that have been identified but have not yet started.
    • In Progress: Tasks that team members are currently working on.
    • Done: Tasks that have been completed according to the team's definition of done.
    • Backlog: A prioritized list of work items, features, bugs, and tasks that may be selected for future work.
