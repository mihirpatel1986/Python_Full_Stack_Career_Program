IT Job Roles and Technology Basics

  1. Name 5 IT Job Roles and Explain What Each Role Does

    • Web Developer: Creates and maintains websites and web applications.
    • Software Developer: Designs, develops, and maintains software applications.
    • Data Analyst: Examines data to identify trends and support decision-making.
    • Network Administrator: Manages and maintains computer networks.
    • Cybersecurity Analyst: Protects computer systems and networks from security threats.

  2. List 3 Product Companies and 3 Service Companies

    Product Companies

    • Microsoft: Develops Windows, Microsoft 365, and other software products.
    • Apple: Creates iPhones, Mac computers, and related software.
    • Adobe: Develops creative software such as Photoshop and Illustrator.

    Service Companies

    • TCS: Provides IT consulting, software development, and technology services.
    • Infosys: Provides IT consulting, digital transformation, and software services.
    • Accenture: Provides technology consulting, cloud, and business services.

  3. Write the Full Forms and One-Line Uses

    • GitHub: A platform for hosting and collaborating on Git-based code repositories.
    • Slack: Searchable Log of All Conversation and Knowledge; a team communication platform.
    • Jira: Jira is a product name, not an official acronym; it is used for project and issue tracking.
    • IDE: Integrated Development Environment; a tool for writing, testing, and debugging code.
    • API: Application Programming Interface; allows different software applications to communicate.

  4. Name 5 Programming Languages and Their Uses

    • Python: Used for artificial intelligence, automation, and data analysis.
    • Java: Used for enterprise applications and backend development.
    • JavaScript: Used to make websites interactive and build web applications.
    • C++: Used in game development and high-performance software.
    • PHP: Used for server-side web development.

  5. Difference Between a Developer and a Tester

    A developer designs, writes, and maintains software code to build applications and implement features.

    A tester checks software for bugs, verifies that it meets requirements, and helps ensure its quality and reliability.
