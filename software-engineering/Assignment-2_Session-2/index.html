Software Architecture and Applications

  1. Three Main Layers of Software Architecture

    • Presentation Layer: The user interface through which users interact with an application.
    • Business Logic Layer: Processes information and applies the application's rules and logic.
    • Data Layer: Stores, retrieves, and manages application data.

  2. Define Client and Server with a Real-Life Example

    Client: A device or application that requests information or services from another computer.

    Server: A computer or software system that receives requests and provides data or services to clients.

    Real-Life Example: When you open YouTube in a browser, your browser acts as the client and YouTube's servers deliver the videos and related information.

  3. Differences Between Desktop, Web, and Mobile Apps

    Desktop Applications

    • Usually installed and run on a desktop or laptop computer.
    • Often designed for a particular operating system, such as Windows or macOS.

    Web Applications

    • Accessed through a web browser and generally do not require traditional installation.
    • Usually require an internet connection, although some support offline use.

    Mobile Applications

    • Designed primarily for smartphones and tablets.
    • Can use mobile features such as GPS, cameras, and push notifications when permitted.

  4. Three Databases and Their Types

    • MySQL — SQL: A relational database that stores data in tables.
    • PostgreSQL — SQL: A relational database that supports complex queries and structured data.
    • MongoDB — NoSQL: A document-oriented database that stores data in flexible, JSON-like documents.
