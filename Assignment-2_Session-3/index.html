Networking and Internet Basics

  1. Full Forms and Uses of Network Protocols

    • HTTP (Hypertext Transfer Protocol): Used to transfer web pages and other resources between a browser and a web server.
    • HTTPS (Hypertext Transfer Protocol Secure): Transfers web data securely using encryption through TLS.
    • FTP (File Transfer Protocol): Used to transfer files between computers over a network.
    • SMTP (Simple Mail Transfer Protocol): Used to send and relay email messages between mail clients and mail servers.

  2. Difference Between IPv4 and IPv6

    IPv4: Uses 32-bit addresses, such as 192.168.1.1, and supports approximately 4.3 billion unique addresses.

    IPv6: Uses 128-bit addresses, such as 2001:db8::1, and provides a vastly larger address space.

  3. Find the IP Address of google.com Using nslookup

    Open Command Prompt on Windows and enter the following command:

    nslookup google.com

    The command displays the DNS server used and one or more IP addresses returned for google.com.

    IP Address: Write the actual IPv4 address shown under the answer section of your command output.

    Note: The returned address may vary depending on your DNS server, location, and time. I cannot run this command on your Windows system directly, so you should record the result from your own computer.

  4. Meanings of HTTP Status Codes

    • 200 OK: The request was successful.
    • 301 Moved Permanently: The resource has permanently moved to a new URL.
    • 404 Not Found: The requested resource could not be found.
    • 500 Internal Server Error: The server encountered an unexpected problem.
    • 403 Forbidden: The server understood the request but refuses to allow access.

  5. DNS Hierarchy Using www.google.com

    • Root (.) : The top level of the DNS hierarchy, which directs queries toward the appropriate TLD servers.
    • TLD (.com): The top-level domain that identifies the domain category or namespace.
    • Domain (google): The registered domain name within the .com namespace.
    • Subdomain (www): A name beneath google.com, commonly used for the website.

    DNS hierarchy: Root (.) → .com → google.com → www.google.com
